# Connectocopter

A whole-brain spiking model of the fruit fly — the FlyWire connectome, 138,639 neurons and 15.1 million connections — reads the sensors of a simulated FPV quadcopter-rover and drives its wheels and rotors in closed loop.

**Status: work in progress.** The full README with results, visuals, setup and limitations is being written; see `docs/` as it fills in.
